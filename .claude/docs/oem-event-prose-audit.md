# OEM Event Prose and Choice-Clarity Audit

Reconciliation baseline: `origin/main` at `abec45ec8831d763d281f133c153174f105f340c`. The original prose survey began at `bcce995f3e0692c3b893a50027f2a1bff3390833`; every retained change was rechecked after the chronology, ownership, and scheduling repairs merged.

The audit covers every fork-owned OEM, corporate-history, semiconductor, computing, cloud, telecommunications, consumer electronics, gaming, AI, and industrial-technology event namespace present at the baseline. It compares each visible description and option with the event's scripted effects and historical date. Hidden reconstruction and callback events were checked for player-facing localisation needs but were not given prose they cannot display.

Brevity alone is not treated as a defect. Text was changed only where it lacked the decision's actors, policy mechanism, or tradeoff; used developer-facing language; misstated chronology; or promised an effect the script does not implement. Every revised visible E3 option now has a player-facing tooltip matching its exact state changes, while event descriptions retain historical context instead of carrying option mechanics. No scheduling, triggers, AI weights, variables, flags, ideas, Treasury effects, research bonuses, or pictures were changed.
