# Russian Computing Sovereignty Source Register

This register covers the reusable event-picture pack for `SOV_computing_sovereignty_events.1` through `.18`. Event `.90` is a hidden state-reconstruction event and intentionally has no picture.

## Derivative Process

- Access date for every source: 2026-08-08.
- Each source was downloaded from the Wikimedia Commons original-file URL recorded below.
- Images were decoded with Pillow, normalized for EXIF orientation, cropped to the `217:163` event-picture ratio, resized to 217 x 163 with Lanczos resampling, and lightly sharpened with an unsharp mask (`radius=0.8`, `percent=70`, `threshold=3`).
- The final files were encoded as legacy DDS with DXT5 block compression and no mipmaps.
- Decode and re-encode removed EXIF, XMP, Photoshop, and other source metadata. A binary signature scan of every DDS found none of those metadata markers.
- The pack uses only CC0 1.0 and CC BY 2.0 sources. CC BY attribution and notices are retained in this register.
